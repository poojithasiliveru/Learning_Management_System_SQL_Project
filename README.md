# 🎓 Learning Management System

## 📖 Project Overview

A **MySQL-based Learning Management System** designed to manage students, mentors, courses, enrollments, and assessment results.

## 🗂️ Main Tables

* **Students** – Student details
* **Mentors** – Mentor information and expertise
* **Courses** – Course details and categories
* **Enrollment** – Student course enrollments and status
* **Assessments** – Assessment scores and dates
* **Assessment_Log** – Assessment activity logging
* **Enrollment_Status_History** – Enrollment status changes

## 🛠️ Technologies Used

* MySQL
* SQL

## 🔍 SQL Concepts Covered

* DDL & DML
* Primary & Foreign Keys
* Joins
* String & Date Functions
* Aggregate Functions
* Subqueries
* Views
* Transactions & Savepoints
* Stored Procedures
* Triggers

## ⚙️ How to Run

1. Install MySQL / MySQL Workbench.
2. Create the database:

```sql
CREATE DATABASE project;
USE project;
```

3. Run the table creation queries.
4. Insert the sample data.
5. Execute the SQL queries to analyze the data.
